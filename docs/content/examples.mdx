# Examples

## React (Vite)

A client-only app: storage, cookies and cross-tab sync.
[Source](https://github.com/iamsomraj/parsistent/tree/main/examples/react-vite)

![Two tabs of the React example staying in sync](https://raw.githubusercontent.com/iamsomraj/parsistent/main/.github/assets/demo.gif)

## Next.js (App Router)

Server rendering: cookies on the first paint, server components, a route handler, and
`localStorage`. [Source](https://github.com/iamsomraj/parsistent/tree/main/examples/nextjs)

![The Next.js example: the theme cookie is server-rendered, so reloading never flashes](https://raw.githubusercontent.com/iamsomraj/parsistent/main/.github/assets/demo-nextjs.gif)

## Run them

```sh
git clone https://github.com/iamsomraj/parsistent.git
cd parsistent/examples/nextjs # or examples/react-vite
npm install
npm run dev
```
